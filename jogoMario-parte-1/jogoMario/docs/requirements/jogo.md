# Requisitos do Jogo Mario

O jogo deve iniciar por uma tela de apresentação, possuir loop com `requestAnimationFrame`, delta time, gravidade responsiva, pulo variável, coyote time, jump buffering, câmera suave com screen leading, colisões ajustadas, moedas, inimigos, HUD, pausa, game over, vitória e recorde persistido em `localStorage`. A execução deve ocorrer a partir de `frontend/` com Vite.
